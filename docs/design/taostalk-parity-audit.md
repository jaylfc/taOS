## Summary of Missing Rows

Unanswered-mention tracking is absent in both codebases - mentions are parsed for routing but no store, API, or UI surfaces pending mentions. Link to a To do item has no implementation in either path; decisions exist but are distinct from todo items. Read receipts have frontend UI and types in Messages App but the backend /api/a2a/messages/{id}/receipts and /api/a2a/receipts endpoints were not found in the routes. Agent presence is fully implemented in Messages App (UI + ChatHub) but completely missing from the taOStalk guest wizard. Threads/replies, @mentions, attachments, and search are all fully implemented in Messages App with backend support but entirely absent from the ConnectWizard guest path.
