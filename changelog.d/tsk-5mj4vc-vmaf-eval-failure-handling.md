### Fixed
- VMAF eval harness (`scripts/library-vmaf-eval.sh` and `scripts/library-vmaf-eval.ps1`) no longer emits `vmaf_mean=0` when a measurement cannot be produced. A non-zero ffmpeg exit now skips the row and prints a diagnostic naming the source/variant pair instead of substituting a score; a missing `VMAF score:` line (for example an ffmpeg build without the libvmaf filter) now emits an explicit `ERROR` marker for `vmaf_mean` and `saving_pct` rather than a number. Both harnesses exit non-zero when any pair was not measured, so a failed or partial run can never be mistaken for a complete evaluation (#tsk-5mj4vc).
