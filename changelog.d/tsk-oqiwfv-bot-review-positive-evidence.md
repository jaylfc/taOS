### Fixed
- CodeRabbit-authored issue comments that are not recognized walkthroughs no longer count as real reviews. The bot-review gate now inverts the fail-open default: only line comments with `source="review_comment"` and `in_reply_to=None` count as real review content. Zero-content notices like "Note: you can re-trigger with @coderabbitai review", "Updated settings from .coderabbit.yaml", "Tracking in #3100", "I will fix that shortly", and ">> [!TIP]\n>> For best results, initiate chat on the files or code changes\n\n@jaylfc Acknowledged." are correctly treated as non-review stubs.
