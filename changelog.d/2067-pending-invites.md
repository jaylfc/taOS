### Added

- **Pending invites surface in the project Members screen and the Agents app (#2067)** — pending invites were previously visible only inside the "Invite external agent" mint dialog, so a minted invite could not be found again without reopening it. The project Members screen now has a "Pending invites" section (invite id, kind chip for agent/collab/cloud-agent, scopes as chips, created time, expiry countdown, PIN-required badge, cancel action, "No pending invites" empty state), and the Agents app registry area lists pending external-agent invites across all projects with a link to the owning project's Members tab and the same cancel action. The invite list serializers now also carry `created_ts` and `pin_required`, and a new read-only admin-gated aggregate `GET /api/agents/invites/pending` feeds the Agents app view; cancellation stays on the existing per-project and OS-level DELETE routes.
