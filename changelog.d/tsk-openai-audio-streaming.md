### Added
- LLM gateway audio: OpenAI streaming options. `POST /api/llm/v1/audio/transcriptions` accepts `stream=true` (with `response_format=json`) and answers `text/event-stream`: one `transcript.text.delta` carrying the whole transcript, then `transcript.text.done` (the on-device model is batch, so there is no partial text). `POST /api/llm/v1/audio/speech` accepts `stream_format` `audio` (the default, raw PCM as before) or `sse`, which sends each PCM chunk as a base64 `speech.audio.delta` and ends with `speech.audio.done` (zero token usage); a daemon failure mid-stream ends the stream without the done event. `stream` accepts `true`, `false` or empty (case-insensitive; `false` and empty are the non-streaming answer) and `stream_format` accepts `audio` or `sse`; any other value of either is a 400, and errors before streaming stay JSON.
