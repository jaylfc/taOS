### Fixed

- **Userspace install SSRF (#971, intermediate hardening)**: `resolve_safe_public_ip` now caches each successful validation (hostname -> validated IPs) for 30s in `tinyagentos/userspace/url_guard.py`, and the new `userspace_fetch_client` factory returns an httpx client whose transport pins every connection to the cached validated IP -- original Host header and TLS SNI preserved -- refusing the fetch when validation fails or an expired entry re-validates to a non-public address. The userspace install route fetches through this factory, so a nameserver that answers public at validation time and internal at connect time cannot bounce the fetch onto an internal address. The full pinned fetch scheduled with the P2 download broker is unaffected and still to come. Follow-up on review: the install route now fetches the original source_url through the factory (its hand-rolled IP-literal rewrite is gone, so the factory's hostname pinning is the live path), DNS validation inside the async transport runs via asyncio.to_thread, and the cache stores only the chosen validated IP (the full resolved set it carried was never read).
