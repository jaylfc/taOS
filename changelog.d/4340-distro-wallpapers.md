### Added

- Desktop distro step 7: `taos-wallpapers` package with the approved taOS wallpaper set (neural, flow, mesh, terrain), dark and light, pre-rendered as JPEG for desktop (3840x2160), ultrawide (3840x1200) and phone (1080x2400), plus an `index.json` with the default marked.
- `taos-wallpaper list|path [--variant dark|light] [--size WxH] [id]` prints the best matching wallpaper file for a size, for any compositor wallpaper tool to use.
