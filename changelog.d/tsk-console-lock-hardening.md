### Changed

- **Stronger device lock** -- the lock screen's PIN sign-in now applies the same request checks as swipe unlock, and its failed-attempt count is kept across controller restarts with a delay that doubles per failed attempt (30 s from the fifth, up to one hour, forgotten slowly while quiet). Locking the screen now ends every session signed in at the device, also after a restart, and such sessions end by themselves after 30 minutes idle. The shell's lock request is confirmed and retried until the controller acknowledges it.
- **Device console identity** -- the device's own screen is recognised by a per-boot secret kept in a file only the shell's user can read (`/run/taos/console-secret`, or `TAOS_CONSOLE_SECRET_FILE`; `TAOS_CONSOLE_SECRET_GROUP` for a shared group). The kiosk starts from `taos-console-url`, which hands the browser a one-time, same-user start ticket. Scripts that talk to the lock-screen routes send `X-taOS-Console: <secret>`. A kiosk started without a ticket shows a notice and offers password sign-in.
- **Lock screen** -- with swipe unlock, "Stop all agents" and "Screenshot" ask for the account password, and screenshots now need a signed-in user. Prompts no longer promise an action that sign-in does not carry out.
