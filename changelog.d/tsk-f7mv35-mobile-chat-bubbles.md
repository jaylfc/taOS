### Changed

- Mobile chat threads now render as modern message bubbles: own messages right-aligned in the accent colour, others in soft grey bubbles with the sender name once per run, avatars at the bottom of each run, a single Read/Delivered line under the last own message, and a hairline Copy footer on agent replies. The per-message toolbar now appears only for the message you long-press, instead of on every message.
- Messages sent from the web client are now recognised as yours (shown as "You" or your display name) instead of the raw "user" id.
