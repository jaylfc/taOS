### Security
- User memory is now private to each person. Members could previously browse, search, change and delete every member's captured chats, notes and file activity, and the agent memory search did not check who asked. Existing shared memory now belongs to the install owner, agents reach a person's memory only through their own memory search, and changing the memory capture settings now needs an admin.
- Changing the install-wide notification mute list now needs an admin.
