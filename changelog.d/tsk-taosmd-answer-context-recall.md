### Added

- Agents now get memory from taOSmd's real `answer_context`: for each recipient the chat router asks for the dated, token-budgeted context of that agent's own memory, with the budget from taOSmd's `default_budget_tokens` (model window, what the prompt already uses, and the model's reasoning reserve). The context sent to the agent is the manual first, then the recalled memory, then the unchanged channel or thread history.
- Memory recall never fails silently. When nothing fits the budget, the window leaves no room, or taOSmd raises, the cause is logged, recorded in the agent's trace, and the agent is told in one line that memory was unavailable for the turn; one agent's failure does not touch another recipient or the shared history. A question with no matching memory adds nothing. This replaces the earlier recall attempts.
