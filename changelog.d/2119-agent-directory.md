### Added

- **Agent directory with self-maintained bios (#2119)** — `GET /api/agents/directory` returns one row per active registered agent: canonical id, handle, display name, bio, role/title, project tags derived from real sponsorship (membership) rows, and an `is_pa` marker read from the Assistant Studio's own PA selection (synced to the `assistant_studio` preference namespace). Each agent maintains its own bio with `PUT /api/agents/registry/{canonical_id}/bio`, authenticated by its own registry token — an agent can set only its own bio (200-char cap, control characters stripped), and derived fields such as project membership are rejected by the bio API rather than silently ignored. Bios are agent-authored free text and are treated as untrusted data by consumers. Follow-up: auto-sync of directory data from the task graph.
