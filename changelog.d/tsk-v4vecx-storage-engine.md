### Added

- **Storage engine: add a disk as a storage area and make it a person's primary home (tsk-v4vecx)** -- `taosctl storage disks|areas|add|set-primary|primary|propose|proposals|approve|reject` and `/api/storage/*`. Every disk is classified `available` or `protected` with the reasons, from lsblk, blkid, wipefs, findmnt, /proc/mounts and /proc/swaps; a disk with any signature, mount, swap, RAID/LVM/ZFS/bcache membership, read-only flag, unknown identity or failed probe, and the system disk, is never offered for formatting. Adding a disk needs the disk's model and serial typed back exactly. The default is btrfs on LUKS2 unlocked at boot with a key file under `/etc/taos/keys`; "shared" is VeraCrypt-encrypted NTFS for dual-boot machines. The format runs in a small root helper (`taos-storage-helper`) that re-runs the safety check itself right before it writes; it is reachable only by the service account, through a validated sudoers entry installed by `scripts/install-storage-helper.sh`. Agents cannot add or assign directly: they file a proposal and a person approves it. See `docs/storage-engine.md`.
