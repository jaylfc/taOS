### Changed

- **CI: the lint job now enforces ruff (#739, Python half)** — `ruff check tinyagentos/` (rules E/F/I, config in `[tool.ruff]` in pyproject.toml, ruff added to the dev group) runs alongside the existing compileall step, so unused imports, undefined names and import-order regressions fail CI instead of landing. Landing the gate meant fixing what it found: 501 violations auto-fixed (import sorting, unused imports, f-string and redefinition cleanups), the rest by hand — including a real bug where `PUT /api/projects/{project_id}/settings/{key}` called `require_owner_or_admin` without importing it and would have raised NameError on every call. E501 (line length) and E402 (deliberate late imports) are grandfathered in the config with their counts recorded; the vitest / npm-audit half of #739 is not in this change.
