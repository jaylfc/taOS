### Fixed

- **Store licence acceptance is person-only and covers every restrictive licence.** The install gate now looks at every licence field of a manifest (`license_class`, `weights_license`, `model_license`, `license`), not just a listed class, so a restrictive or unrecognised licence always asks first. Only a person's own session can accept: agent tokens, service tokens and every registry JWT get `agent_cannot_accept_license`. The acceptance text is built in full (licence name, version, link) with no placeholders, and the record keeps licence name, version, link, person and time. A new licence version needs a fresh acceptance and the older record is kept.
- **Region-limited licences use a person-level country.** Settings, Account has a Country setting (desktop and phone), and the Store asks for it at install time when needed. The install only fails closed when the country is unset AND the licence is territory-limited, and the message says how to set it. An excluded country is refused even after acceptance. The country is never guessed from the network address.
- `scripts/check_manifests.py` (and `tests/test_check_manifests.py`) now fail on any licence string the policy allowlist does not know.
- **One licence gate for every install path.** The gate lives in `tinyagentos/license_gate.py` and runs for `/api/store/install` (used by `taosctl store install`), `/api/store/install-v2`, the model download route, taOSmd setup, the shared legacy installer (setup wizard backends), a backend pulled in by an install chain, and MCP marketplace installs. A caller with an agent or CLI token gets the 412 with the text the person must accept; it can never accept for them.
- **Phone Store licence and country steps.** The phone Store no longer shows an endless Retry on a licence or country 412; it opens the same licence and country dialogs as the desktop Store.
