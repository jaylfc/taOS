### Added
- App type indicators: an `AppRuntime` model (`taos` | `linux` | `android` | `web` | `container` | `agent`), an optional `runtime` field on `AppManifest` (app-registry.ts), and `appRuntime`/`shellWindowRuntime` derivation (lib/app-runtime.ts). Built-in apps default to `taos`; `service:` ids are `container`; userspace rows map `ai-generated` provenance to `agent` (winning over `container`) and `container` app_type to `container`, else `web`. `shellWindowRuntime` classifies taOSmobile compositor windows (`waydroid.` -> android, `chrome-` -> taOS, else linux).
- `AppTypeBadge` component: a bottom-right circular chip (badge mode) or an inset outline ring (outline mode) showing what TYPE of app an icon is. Renders nothing for `taos` apps or when indicators are off. Lucide glyphs (Terminal, Smartphone, Globe, Box, Sparkles), `sm`/`md`/`lg` sizes (12/16/20px), per-type `--app-type-*` CSS tokens, and an accessible `aria-label` + `sr-only` label on every rendered element. The user-toggleable `appTypeIndicator` setting (badge/outline/off) is persisted in localStorage and validated against `APP_TYPE_INDICATOR_OPTIONS` (theme-store.ts).
