### Added
- Device voice routes, device bearer only. `POST /api/device/v1/voice` (scope `voice:stt`) takes raw PCM16 16 kHz mono (at most 30 s) and returns `{"text"}`. `POST /api/device/v1/voice/tts` (scope `voice:tts`) takes `{"text", "sample_rate"}` and streams PCM16 mono (`audio/pcm`) at the native 22050 Hz, or 16 kHz when asked, with `X-Sample-Rate` and `X-Channels` headers; any other rate is a 400. Both run on the local speech daemons through the same in-process code as the gateway routes, answer `409 stt_not_installed` / `tts_not_installed` when Speech is not installed and `503` when the daemon is down, and never log or keep the text or the audio. Tokens issued before scopes existed do not gain voice; embedded devices need the Talk set (`voice:stt voice:tts chat:send`) and the TLS listener.
