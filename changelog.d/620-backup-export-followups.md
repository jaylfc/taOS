### Changed

- **Backup/export bundle follow-ups (#620)** — three gaps left open when the export shipped are closed: mapping keys that are themselves absolute paths are rewritten like path values (relative to the data dir, or reduced to their final component), so a path-shaped key no longer leaks the host layout; `env` sections are allow-listed — only locale, timezone and terminal presentation variables (`LANG`, `LC_*`, `TZ`, `TERM`) keep their values, and every other variable's value is redacted and recorded, since an innocent name can still hold a credential; and when two source keys sanitise to the same output key, the later entry is kept under a suffixed key with the collision recorded in the manifest instead of silently dropping a value.
