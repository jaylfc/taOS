### Added

- GET `/api/device/v1/agents/{name}/avatar?size=<px>` — device-bearer route (scope `agents:read`) serving server-side converted LVGL 9 RGB565A8 circle-masked avatars. Size whitelisted to 45 and 96. ETag/304 caching with `ETag: "<avatar_hash>-<size>"`. Server-side cache under `<data_dir>/cache/device-avatars/<agent_key>/<hash>-<size>.lvimg` (atomic write, per-agent isolation, auto-invalidation on avatar change). Non-owned/unknown agents return 404 (never 403, no name leak). Shared agents (user_id missing or empty) are served to any device owner. Undecodable source images return 404 `avatar_not_found` (never 500). RGB565 in native little-endian; transparent pixels have RGB565=0x0000 (black).
