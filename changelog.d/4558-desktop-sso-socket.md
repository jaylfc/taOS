### Added

- **Desktop single sign-on**: a native desktop session can get the taOS session of its own Linux account with no password. The controller listens on a unix socket (`/run/taos-sso/desktop-sso.sock`, a directory any local account can traverse, always listening: the link file is read on every request, so it may appear later with no restart), reads the caller's uid from the kernel (SO_PEERCRED) and maps it through a root-owned link file (`<uid> <taOS username>`) to exactly that person. The request carries no username, so a uid can never receive someone else's session; unlinked uids, root and container uids get a refusal. One live session per (uid, kind) so an ssh login never kicks the desktop; each renewal revokes that kind's previous session and `release` revokes the current one. A link file that is not root-owned, is group/other-writable, or is a symlink is ignored. `python -m tinyagentos.desktop_sso link|unlink|list` is the root helper that edits the file.
