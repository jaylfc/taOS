- Registered agents can now request new project creation via `POST /api/agents/auth-requests` with `kind: "project_create"`. The agent authenticates with its own registry Bearer token (identity only, no scope grant required). If the requested name or slug is already taken the request is auto-rejected with a 409 and field-specific suggestions (no Decision is raised); otherwise a pending `approve_deny` Decision is queued in the Decisions app for admin approval. Approving the Decision creates the project and sets the requesting agent as its lead (membership role + `lead_member_id` pointer), then posts a structured A2A reply back to the asking agent; denying it creates nothing.
