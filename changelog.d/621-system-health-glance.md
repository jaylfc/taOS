### Added

- **System health glance (#621)** — the Activity app opens with a compact "System health" card answering "is everything healthy" at a look: LLM gateway, agents running/stopped, cluster workers online, container backend, model backends, memory pipeline and recent errors, each with an OK / Degraded / Error / Unknown state and a headline verdict. Every unhealthy row links into the app that owns the fix (Agents, Cluster, Memory, Providers). The card only consumes existing endpoints (`/api/health?detailed=true`, `/api/health-check`, `/api/agents`, `/api/memory/stats`); CPU/RAM/disk/scheduler keep their dedicated Activity cards and are not duplicated. The issue's "LiteLLM proxy" item maps to the in-process LLM gateway that replaced the proxy process (LiteLLM removal stage 2b-2a), so the gateway row tracks the controller health probe.
