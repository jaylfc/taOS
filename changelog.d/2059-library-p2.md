### Added

- **Library P2: YouTube cheap tier completed + web ingestor failure states (#2059)** — the `url:youtube` processor now stores the video description as its own indexed text artifact (the fetcher previously dropped it), captures subtitles/transcripts in **all available languages** (one transcript artifact per language, with the language recorded; previously English only), and records explicit failure states on the item card data instead of silent or generic failures: `transcript_status: unavailable` when a video has no captions, and a classified `youtube_fetch_state` (`unavailable` / `geo_blocked` / `private` / `timeout` / `fetch_failed`) with the specific yt-dlp reason as the item error when the video cannot be fetched at all. The `url:web` processor likewise records `text_status: no_text_extracted` when a fetched page yields no readable text. The YouTube fetcher's return contract stays backward compatible (`content` remains the primary transcript). Not in this slice: the web processor's full-page screenshot artifact, which needs the browser subsystem (CDP container lifecycle) wired into the pipeline — the readability extract is the indexed text artifact today.
