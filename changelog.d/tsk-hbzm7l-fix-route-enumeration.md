### Fixed
- Auth middleware now returns 404 directly for authenticated callers on unknown routes instead of 401. This fixes a bug where a wrong URL was indistinguishable from dead credentials. The auth middleware runs before routing, so previously routing failures were reported as auth failures. The fix returns 404 from the middleware itself without calling routing, while unauthenticated callers still get 401 for anti-enumeration (issue #tsk-hbzm7l).
