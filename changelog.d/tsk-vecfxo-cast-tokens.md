- Screencast groundwork: a signed-in owner can start a cast of one project canvas to one device (`POST /api/cast/sessions`), which renders the canvas host-side as a still image served at `/cast/media/...` behind a short-lived cast token. The token is a separate random secret stored only as a hash, scoped to that one view, refreshable while the cast is active, revoked on cast-end (`DELETE /api/cast/sessions/{id}`) and on device unpair, and optionally bound to the device's address; it is never accepted as a session or bearer. Live (HLS) casting is not available yet and answers 501.
