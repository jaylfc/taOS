### Fixed
- Every memory write taOS makes to taOSmd now carries session_id, turn_index, session_date and turn_owner: chat HTTP and WebSocket, channel hub inbound and outbound, bridge sessions (final, tool call, tool result, reasoning, error) and workspace file activity. The turn index comes from one shared persisted per-session counter that is atomic under concurrent posts and continues after a restart; a value that cannot be determined is written and logged as "unknown", never 0 or an empty string. Supersedes the earlier attempts that left channel hub hardcoded to 0 and counted at different points on the HTTP and WebSocket paths.
- User memory is now per person: browse, search, stats, settings, save, delete and file-upload capture use the signed-in user's id. The install owner also keeps seeing chunks written before this change (the old shared partition, read in place and never copied); members never see them.
