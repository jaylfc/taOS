### Changed
- Desktop preferences are now stored per-person: each signed-in user gets their own settings row; new users start with shipped taOS code defaults (never the admin's global row). A one-time migration moves the legacy global `user` row to the primary admin's user_id. PUT endpoints for `/api/desktop/settings`, `/api/desktop/dock`, and `/api/preferences/{ns}` now require a session user (any member) and refuse local/agent tokens (403). UI error handling no longer swallows failed persistence calls.
