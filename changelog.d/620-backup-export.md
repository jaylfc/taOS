### Added

- **Backup/export bundle (#620, slice 1: export)** — new admin-only `GET /api/settings/export` (Settings → Backup & Restore → "Export Bundle (JSON)") downloads a structured JSON bundle of the install's configuration and data: config, agents (config-defined plus registry identities), projects with their membership, per-user notification prefs/DND, and desktop settings/preferences. Unlike the legacy `POST /api/backup` tarball — which ships `config.yaml` verbatim — secret values never appear in the bundle: fields under secret-bearing keys (the `log_redaction` key list) carry the `[REDACTED]` marker, credential-shaped strings and literal secrets-store values are scrubbed wherever they appear, and the secrets store contributes only name/category references so a future import can prompt for re-entry. The bundle opens with a manifest (`format`, `format_version`, `exported_at`, `taos_version`, section list) whose `excluded` list records every redaction and deliberate omission, so nothing vanishes silently and a later import slice can validate the bundle before applying it. Import/restore of a bundle is the follow-on slice.
