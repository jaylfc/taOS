### Added
- The model scheduler now tracks which model is serving a request. A model is marked in use exactly while a gateway request for it is in flight, so the idle unloader never evicts a busy model. One small context manager owns the count for every OpenAI-compatible and Anthropic request, streaming or not, keyed by the model and backend that actually serve it (not the alias the caller typed). It is released on every exit: key failure, upstream error, client disconnect, cancellation, early close, failover to another backend, and an error while recording the trace. A request that fails before any byte streams records no trace and no spend. The scheduler is built in `tinyagentos/app.py` as `app.state.model_scheduler` and looks a backend's resource shape up by its type.
