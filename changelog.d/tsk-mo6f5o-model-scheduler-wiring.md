### Added
- Wired CoreAwareModelScheduler into the live gateway forward path for model residency tracking and in-use accounting. The scheduler is constructed at app startup (`tinyagentos/app.py:1501`) as `app.state.model_scheduler` with the Model Activity feed. Every real chat request (non-streaming, streaming, Anthropic) now calls `begin_use(model, backend)` before the request and `end_use(model)` in a finally block after (success, error, timeout, stream end, client abort). The `LoadedModel` record gains an `in_use_count` field; eviction and shrink-reload paths in `core_aware_scheduler.py` skip models with non-zero in-use count. Scheduler errors never fail or delay requests (wrapped like `_notify_lifecycle`).
