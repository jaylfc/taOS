### Fixed

- **Gate-integrity defect**: every gate workflow triggered on `pull_request` checked out the PR merge ref and executed its checker from that checkout, so a PR could modify its own required gate script (or the workflow file itself) and make the check pass while disabling detection. Added `gate-integrity.yml` (runs on `pull_request_target`, inspects the PR diff via the GitHub API, never checks out PR code) and `scripts/check_gate_integrity.py`, which fails when the PR touches `.github/workflows/` or any gate-checker script (`check_bot_review.py`, `check_deleted_symbols.py`, `check_doc_gate.py`, `check_schema_migrations.py`, `check_retrofit_migrations.py`, `check_manifests.py`, `check_secret_ignores.py`, `check_store_wiring.py`, `.github/scripts/check_all_skip.py`) unless the PR carries the explicit allow label `gate-integrity-allowed`.
